# crow workshop

The workshop that distills software-engineering experts' skills and writing into **crow**, a personal agent skill package for Claude Code and Codex.

## Language

**Blueprint**:
The complete set of design decisions for a crow version (taste charter, chosen skills, and each skill's design) from which every skill can be written without further deciding.
_Avoid_: plan, spec, roadmap

**Taste charter**:
The user's ranked engineering values, ranked writing values, hard constraints and anti-goals, against which every conflict between sources is ruled.
_Avoid_: principles, guidelines, style guide

**Hard constraint**:
A charter requirement that sits outside the rankings: a candidate that fails it is out, whatever it scores on values.
_Avoid_: must-have value, top value
