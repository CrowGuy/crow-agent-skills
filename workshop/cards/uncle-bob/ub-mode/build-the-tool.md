# Build a tool for work that is not obvious at a glance

## Claim

When the work is not obvious at a glance, build a tool that does it. Do one unit
of the work by hand first, then make the tool reproduce that unit.

## In its own words

> If the work is not obvious at a glance, build the tool that does it. (SKILL.md:58)

> Do one unit by hand, then make the tool match that unit. (SKILL.md:59)
