# Redesign as if a new requirement had been there from the start

## Claim

Do not attach a new requirement to the old design. Work out what you would have
built had the requirement existed from the start, then deliver that design in pieces.

## In its own words

> Do not bolt a new requirement onto the old design. (SKILL.md:38)

> Ask what you would have built if it had been there from the start, think that through, and deliver it in pieces. (SKILL.md:39)
